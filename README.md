# ForgedFitness

A free gym-style fitness PWA for iPhone, with workouts, meal shortcuts, recipes, streaks, milestones, weight tracking, and an on-device macro estimator.

## Run on your phone

1. In GitHub, open repository **Settings → Pages**.
2. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
3. Wait for GitHub Pages to publish. The site should be `https://arctiixy.github.io/forged-fitness/`.
4. Open it in Safari and optionally choose **Share → Add to Home Screen**.

If the page remains on “Starting ForgedFitness…”, close the old tab and open `https://arctiixy.github.io/forged-fitness/?refresh=8` to fetch the latest version. The app attempts to show a readable error instead of leaving the startup message if dashboard rendering fails.

## Macro estimator

The free estimator runs on the device; it is not AI and sends no personal details to a service. It uses a common resting-energy equation and rough macro rules to generate an estimate. It is for adults only, can be inaccurate, and is not a medical prescription. Do not rely on it for pregnancy/breastfeeding, eating-disorder history, or medically managed nutrition; ask a GP or registered dietitian for personal advice.

App data is stored in this browser on this device. Clearing browser data can erase it.
